# LAGUNA ATHLETIC - Control de Asistencia y Gestión del Plantel 2026

Plataforma oficial de **Laguna Athletic (Temporada 2026)** para control de asistencia, convocatorias, alineaciones tácticas, avisos por WhatsApp y seguimiento de estadísticas.

## 🚀 Módulos del Sistema

1. **📱 Registro QR**: Registro instantáneo al llegar a la cancha.
2. **⚽ Convocatoria y 11 Titular**: Pizarra táctica interactiva (Formación 4-3-3).
3. **💬 Avisos WhatsApp**: Envío automatizado de avisos a jugadores y tutores.
4. **📅 Calendario del Club**: Programación de entrenamientos y partidos oficiales.
5. **📋 Justificaciones**: Gestión de ausencias y revisión por el Director Técnico.
6. **📊 Estadísticas**: Gráficos de % de asistencia y ranking de cumplimiento.
7. **🔒 Permisos por Rol**: Acceso diferenciado para Entrenador (DT), Jugadores y Directiva.

## 💻 Tecnologías

- **Frontend**: HTML5, CSS3 Modo Oscuro Premium, JavaScript ES6+
- **Librerías**: FontAwesome 6, Chart.js, QRCode.js
- **Assets**: Escudo oficial del club (`LAGUNA.jpg`) y vectorización (`logo.svg`)
